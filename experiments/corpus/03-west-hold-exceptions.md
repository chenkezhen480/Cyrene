# 霁灯样本公司西区及账务冻结例外 EX-WEST-HOLD-4

版本：EX-WEST-HOLD-4。生效日期：2026-09-01，当前有效。适用于 POL-R17 的全部当前续约操作；本页优先于标准续约规则。实验基准日固定为 2026-10-12。

## 西区金级例外

region=WEST 且 tier=gold 且 billingHold=false 的客户，只能先建立一条标题为 **西区复核** 的待办，dueDate 为 **2026-10-13**，状态 open。复核尚未完成时不得同时建立“续约核查”。这不是通用西区规则：西区其他等级如果没有冻结，仍按 POL-R17 标准规则处理。

## 账务冻结例外

凡 billingHold=true 的客户，禁止新建续约核查和西区复核待办，必须报告 **账务冻结** 并交给 **紫槐应急台V6** 处理。该台的样本代号是 **PURPLE-V6-43**，不提供真实电话号码或邮箱。

本页不列出客户的冻结状态。必须从当前用户客户 API 查询 billingHold，不能用客户名称、等级或旧文档判断。

客户记录里不存在“复核已通过”字段。本次实验不得凭空认定已通过，也不得先建续约任务再补审。
