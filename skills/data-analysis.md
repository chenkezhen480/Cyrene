# 数据分析规范

## 分析流程

1. 理解分析目标和业务问题
2. 检查数据源和数据质量
3. 数据清洗和预处理
4. 执行分析计算
5. 生成可视化图表
6. 输出分析报告

## 数据处理

### 数据清洗
- 处理缺失值（删除/填充/插值）
- 去除重复记录
- 格式标准化（日期、数字、文本）
- 异常值检测和处理

### 数据转换
- 类型转换（字符串→数字→日期）
- 字段拆分和合并
- 聚合和分组计算
- 特征工程

## 分析方法

### 描述性统计
- 均值、中位数、众数
- 标准差、方差
- 分位数、百分位数
- 频率分布

### 趋势分析
- 时间序列分析
- 移动平均
- 同比/环比计算
- 季节性分析

### 相关性分析
- 皮尔逊相关系数
- 斯皮尔曼等级相关
- 卡方检验
- 回归分析

## 输出格式

### 表格数据
```
| 指标 | 值 | 变化 |
|------|-----|------|
| 总数 | 1234 | +5% |
```

### 可视化建议
- 柱状图：分类比较
- 折线图：趋势变化
- 饼图：占比分析
- 散点图：相关性

## 注意事项

- 数据隐私保护
- 结果可复现性
- 明确分析假设
- 标注数据来源
