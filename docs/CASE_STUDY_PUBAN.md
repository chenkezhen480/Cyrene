# 谱伴应用案例

更新日期：2026-10-14。应用阶段由项目维护者确认：**已在线下机构试点，约 100+ 用户**。

## 场景与工作流程

谱伴面向孤独症儿童的个性化成长支持，把专业人员确认的个体目标转为可参与的绘本情景和互动练习。业务链路连接档案与目标读取、绘本生成、人工审核与保存、互动练习和反馈记录。

IEP 指个别化教育计划。儿童档案、目标制定、内容适配及审核属于应用系统与专业人员的职责。Cyrene 提供通用 Agent 运行设施，不在框架中固化儿童领域模型或专业判断。

## Cyrene 如何接入现有业务

这个场景对应已有系统接入 Agent 的两个核心问题：

- **懂系统：** 专业知识、儿童历史记录与目标关系为个性化内容提供依据。知识与记忆按任务相关性选择，让已有数据参与判断。
- **会操作：** 将宿主的档案、目标、绘本保存和互动接口转为 Agent 工具，使用可信用户与租户身份、业务凭证发起调用，由宿主校验权限。

独立 Agent 服务复用这些通用设施，宿主保留业务数据模型与专业审核流程。接口接入提供操作业务数据的根基，知识与记忆组织发挥既有数据价值，Trace 则保留选择、结果与反馈，形成经审核的业务微调样本。

| 内容 | 当前定位 |
|---|---|
| 个体目标、绘本、审核、互动和反馈链路 | 线下机构试点应用的业务流程 |

| 基于绘本情景的互动游戏 | 应用互动功能 |
| 以表达求助为例，适配不同参与方式 | 产品设计示例 |
| 知识、运行快照与记忆 | Cyrene 提供的通用运行与数据利用设施 |
| Trace 数据用于业务微调 | 经审核组织样本，优化对应业务中的选择与决策权重 |
| 青春期、转衔与成年支持 | 长期方向，当前聚焦儿童场景 |

## 应用与框架的责任

| 责任 | 谱伴及其宿主系统 | Cyrene |
|---|---|---|
| 业务数据 | 儿童档案、IEP、绘本与任务数据 | 接收获授权的请求上下文与工具结果 |
| 专业审核 | 确认目标、材料适配与反馈 | 为审核流程提供可调用的接口与结构化结果能力 |
| 身份权限 | 认证用户与租户，校验业务 API 的数据权限 | 绑定可信身份，限制请求级工具目录，读取知识时重新授权 |
| Agent 执行 | 提供业务 API 和领域知识 | 通用 HTTP 工具、自主 ReAct、会话、子 Agent、知识读取与 Trace |
| 数据利用与模型优化 | 决定授权、脱敏、样本准入、业务微调与专业评价 | 记录工具选择、结果与反馈，为业务样本保留执行过程与来源 |

知识与记忆的权重影响当前任务的上下文选择；审核后的 Trace 样本用于业务模型微调，优化工具选择、操作步骤与决策权重，使执行数据发挥二次价值。应用及维护方负责样本使用范围和模型效果评价。
