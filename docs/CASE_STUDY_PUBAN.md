# 谱伴应用案例

记录日期：2026-10-13。应用阶段由项目提供者确认：**可运行原型 / 演示**。

## 场景与工作流程

谱伴面向孤独症儿童的个性化成长支持，把专业人员确认的个体目标转为可参与的绘本情景和互动练习。流程设计为：IEP 与儿童当前状态 → 个性化绘本 → 内容审核 → 互动练习 → 反馈确认 → 下一轮任务。

IEP 指个别化教育计划。儿童档案、目标制定、内容适配及审核属于应用系统与专业人员的职责。Cyrene 提供通用 Agent 运行设施，不在框架中固化儿童领域模型或专业判断。

## 应用与框架的责任

| 责任 | 谱伴及其宿主系统 | Cyrene |
|---|---|---|
| 业务数据 | 儿童档案、IEP、绘本与任务数据 | 接收获授权的请求上下文与工具结果 |
| 专业审核 | 确认目标、材料适配与反馈 | 为审核流程提供可调用的接口与结构化结果能力 |
| 身份权限 | 认证用户与租户，校验业务 API 的数据权限 | 绑定可信身份，限制请求级工具目录，读取知识时重新授权 |
| Agent 执行 | 提供业务 API 和领域知识 | 通用 HTTP 工具、自主 ReAct、会话、子 Agent、知识读取与 Trace |
| 训练与发布 | 决定授权、脱敏、训练准入与专业评测 | 当前提供运行记录；自动训练发布闭环仍属于规划 |

这是现实领域的应用原型案例。它证明已有具体应用设计与功能展示；合成 CRM 实验则提供可重复的工具行为对照，两者承担不同的验证任务。
